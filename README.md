# 📊 Power BI Capstone Project – E-commerce Sales Dashboard  

## 🔎 Overview  
This project is a **Power BI Capstone** where I designed and developed a **comprehensive dashboard** to analyze an e-commerce dataset of **100K+ records**.  
The dashboard answers **8 critical business questions** related to sales performance, customer trends, delayed deliveries, and seller performance.  

The repository contains:  
- `PowerBI_Dashboard.pbix` → Interactive Power BI dashboard  
- `Report.doc` → Detailed documentation with visuals, explanations, and insights  

---

## 🎯 Key Features  
- **8 Business Questions Answered** through interactive visuals  
- **Sales Performance Analysis** (Top categories, states, sellers)  
- **Customer Insights** (geographical trends, order behavior)  
- **Delayed vs. On-time Deliveries** with drillthrough to **Delivery Insights page**  
- **Slicers for State and Time** to filter and interact with data  
- **ETL Steps in Power Query** – data cleaning, deduplication, header promotion, and text formatting  

---

## 📌 Business Questions Covered  
1. Overall Sales Trend Over Time  
2. Top 10 Product Categories by Sales  
3. Sales Distribution by Customer State  
4. Seller Performance by Revenue  
5. Average Delivery Time Analysis  
6. Order Counts by Payment Type  
7. Customer Growth Over Time  
8. Delayed vs. On-Time Deliveries (with Drillthrough to Delivery Insights)  

---

## 🛠️ Tech Stack  
- **Power BI Desktop** (Dashboard development, DAX, drillthroughs, slicers)  
- **Power Query** for ETL and data cleaning  
- **Excel/CSV Dataset** (~100K+ rows)
